## Общая информация
- Проект: Учебный интернет-магазин. Фронтенд (чистый HTML/CSS/JS) + Бэкенд (FastAPI).
- Стек: Python 3.10+, FastAPI, SQLAlchemy 2.0, Alembic, Pydantic v2, SQLite.

## Жесткие ограничения
1. **НЕ ИЗМЕНЯЙ CSS-КЛАССЫ И HTML-СТРУКТУРУ** без явного указания. Мы сохраняем текущую верстку.
2. **НЕ ИСПОЛЬЗУЙ `json.dumps`** для полей типа JSON в SQLAlchemy. Пиши списки напрямую.
3. **НЕ ИСПОЛЬЗУЙ** `passlib` и `python-jose`. Используй `argon2-cffi` и `PyJWT`.
4. В Pydantic v2 `Optional[str]` **обязательно** должно быть `Optional[str] = None`, если поле необязательное.
5. **ОБРАБОТКА ОШИБОК:** Никаких `except Exception as e: raise HTTPException(500, detail=str(e))`. Ошибки обрабатываются глобально в `errors.py`. 
6. **ПРАВА ДОСТУПА:** Все эндпоинты создания/редактирования/удаления товаров и статей должны быть защищены зависимостью `require_admin`.

## Стиль кода
- Используй типизацию (Type Hints) везде.
- Пиши короткие, понятные функции. Бизнес-логику выноси в `crud`, роутеры оставляй тонкими.
- Все секреты — только через `config.py` (pydantic-settings), никакого хардкода типа `"my-secret-key"`.
